photon_platform.clerk.track.core.get_frontmatter_and_content(file_path: pathlib.Path) → tuple[dict, str]¶

Extract frontmatter and content from a markdown or RST file.

For MD: Assumes frontmatter is between the first two ‘—’ lines. For RST: Assumes field lists at the top (e.g. :order: 1).
